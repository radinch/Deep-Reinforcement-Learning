# Multi-Agent Learning

Game-theoretic learning dynamics and centralized versus decentralized critic comparisons on VMAS Navigation. Rendering setup in the navigation notebook targets Linux/Colab; see [running notes](../../docs/running.md).

## Notebooks

- [fictitious_play.ipynb](fictitious_play.ipynb)
- [cooperative_navigation.ipynb](cooperative_navigation.ipynb)

## Running

From this directory, install `requirements.txt`, launch JupyterLab, and run the selected notebook in order. Existing outputs are retained. See the [shared setup notes](../../docs/running.md) for environment and compatibility details.
