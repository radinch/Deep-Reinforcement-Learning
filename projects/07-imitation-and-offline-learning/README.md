# Imitation and Offline Learning

Behavior cloning and DAgger in MiniGrid DoorKey, adversarial imitation with GAIL, and an offline actor-critic comparison using behavior regularization.

## Notebooks

- [minigrid_imitation.ipynb](minigrid_imitation.ipynb)
- [gail.ipynb](gail.ipynb)
- [ddpg_behavior_cloning.ipynb](ddpg_behavior_cloning.ipynb)

## Running

From this directory, install `requirements.txt`, launch JupyterLab, and run the selected notebook in order. Existing outputs are retained. See the [shared setup notes](../../docs/running.md) for environment and compatibility details.
