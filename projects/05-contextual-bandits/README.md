# Contextual Bandits

Text moderation policies using contextual bandit feedback, with regret, risk, calibration, and off-policy evaluation. Dataset access or a local TweetEval cache is required. The original supporting PDF is retained in `reports/`.

## Notebooks

- [textual_contextual_bandits.ipynb](textual_contextual_bandits.ipynb)

## Running

From this directory, install `requirements.txt`, launch JupyterLab, and run the selected notebook in order. Existing outputs are retained. See the [shared setup notes](../../docs/running.md) for environment and compatibility details.
