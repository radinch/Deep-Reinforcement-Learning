# Policy Gradient Methods

REINFORCE variants on CartPole and a geometric comparison of vanilla and natural policy gradients in MiniTetris. CartPole policy rollouts are available in `media/`. The REINFORCE notebook uses the legacy Gym API.

## Notebooks

- [reinforce.ipynb](reinforce.ipynb)
- [natural_policy_gradient.ipynb](natural_policy_gradient.ipynb)

## Running

From this directory, install `requirements.txt`, launch JupyterLab, and run the selected notebook in order. Existing outputs are retained. See the [shared setup notes](../../docs/running.md) for environment and compatibility details.
