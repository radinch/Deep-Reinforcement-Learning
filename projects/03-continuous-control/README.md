# Continuous Control

Deterministic actor-critic methods for a moving-target Reacher environment. Rerunning requires the original `HW3_moving_target_reacher_env.py`, which was not included in the source archive. See [running notes](../../docs/running.md#missing-local-modules).

## Running

From this directory, install `requirements.txt`, launch JupyterLab, and run the selected notebook in order. Existing outputs are retained. See the [shared setup notes](../../docs/running.md) for environment and compatibility details.
