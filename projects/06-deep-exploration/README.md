# Deep Exploration

Comparison of exploration methods on normal and noisy DeepSea. `results/` contains the original numerical artifacts; `modules/` contains three implementation modules recovered from notebook cells. The remaining benchmark modules must be restored before rerunning; see [running notes](../../docs/running.md#missing-local-modules).

## Notebooks

- [deepsea_exploration.ipynb](deepsea_exploration.ipynb)

## Running

From this directory, install `requirements.txt`, launch JupyterLab, and run the selected notebook in order. Existing outputs are retained. See the [shared setup notes](../../docs/running.md) for environment and compatibility details.
