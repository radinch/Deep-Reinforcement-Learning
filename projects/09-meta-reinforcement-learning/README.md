# Meta-Reinforcement Learning

Fast adaptation to hidden target velocities in HalfCheetahVel, comparing gradient-based, recurrent, and latent-inference mechanisms. The notebook includes learning curves and held-out-task adaptation evaluation.

## Notebooks

- [halfcheetah_meta_rl.ipynb](halfcheetah_meta_rl.ipynb)

## Running

From this directory, install `requirements.txt`, launch JupyterLab, and run the selected notebook in order. Existing outputs are retained. See the [shared setup notes](../../docs/running.md) for environment and compatibility details.
