# Model-Based Planning

Dyna-Q and prioritized sweeping on CliffWalking, alongside Monte Carlo tree search and naive search with learned model components. The search notebook is an educational study of MuZero-style planning.

## Notebooks

- [dyna_q.ipynb](dyna_q.ipynb)
- [mcts_learned_models.ipynb](mcts_learned_models.ipynb)

## Running

From this directory, install `requirements.txt`, launch JupyterLab, and run the selected notebook in order. Existing outputs are retained. See the [shared setup notes](../../docs/running.md) for environment and compatibility details.
